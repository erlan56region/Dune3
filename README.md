# Dune3

Структура рабочего пространства организована в 3 основные папки:

- `html-игры/` — автономные HTML-версии игры **DUNE II — Битва за Арракис**:
  - `html-игры/arrakis-remaster/index.html` — версия `REMASTER` (148 092 байта);
  - `html-игры/dune2-ver-1.4/index.html` — исходная версия `ver. 1.4` (140 447 байт, ранее `uploads/index (1).html`).
- `OpenGame/` — полный исходный код фреймворка OpenGame (включая `agent-test/debug-skill/` и `agent-test/docs/`).
- `обновление-кода/` — выделенная папка для будущих обновлений, патчей и доработок кода.

Дополнительно в корне сохранён исходный резервный архив `Arrakis_workspace_backup.zip`.
