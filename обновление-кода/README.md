# Обновление кода

Папка предназначена для будущих обновлений, патчей, diff-файлов и новых версий кода (для HTML-игр и `OpenGame`).

Рекомендуемая структура для добавляемых материалов:
- `patches/` — патчи и diff-файлы изменений;
- `releases/` или отдельные подпапки по дате/версии (например, `v1.5/`) — обновлённые версии и доработки.
